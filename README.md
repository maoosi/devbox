# devbox

My dev environment bootstrap for fresh Linux machines.

## Quick Start

```bash
curl -fsSL https://raw.githubusercontent.com/maoosi/devbox/main/bootstrap.sh | bash
```

## What's Included

| Category | Tools |
| --- | --- |
| System | build-essential, curl, wget, git, zip/unzip |
| GitHub | gh CLI |
| Node.js | fnm + LTS |
| Package Managers | pnpm, Bun |
| Toolchain | Vite+ (alpha) |
| Containers | Docker |
| AI | Claude Code CLI |
| Secrets | Infisical, Doppler |
| Claude Config | `.claude/` skills auto-installed to `$HOME` |
